§ 01 Principles

Six rules we hold every ship to.

Short enough that leadership, design, and engineering all remember them by Friday.

#idrule — descriptionscope
01onboarding · first-run

Make the first minute the best minute.

If a new user can't do one real thing in sixty seconds, the product has failed before it's begun.

Scope · all surfaces→
02ai · transparency

Show the work, not the magic.

Every AI output ships inspectable, editable, and attributable — never a black box the user has to trust on faith.

Scope · AI surfaces→
03interaction · hierarchy

Every click is a cost.

Default to the action the user came for. Hide the rest behind intent — menus, modals, or muscle memory.

Scope · all surfaces→
04states · feedback

Loud states, quiet chrome.

Errors, progress, and empty states deserve real design attention. Navigation and containers do not.

Scope · components→
05copy · voice

Write like a person, not a product.

Specific, direct, short. No exclamation marks, no "Oops!", no marketing copy leaking inside the app.

Scope · all copy→
06craft · a11y

Ship the boring polish.

Focus rings, keyboard nav, empty states, offline. The work no one notices is the work that matters.

Scope · all surfaces→
